# freelance-site — «Фриланс.Рядом»

Сайт-биржа фриланса: главная страница с заданиями, каталог заказов, форма заказа и страница благодарности.
Ручной HTML/CSS/JS без конструкторов и фреймворков.

Живая версия: https://podrabotka-ryadom.ru

## Страницы
- `index.html` — главная: заголовок, поиск, блок категорий, карточки заданий
- `list.html` — каталог заданий с фильтрами
- `order.html` — форма размещения заказа
- `thanks.html` — страница после отправки формы

## Стек
- HTML5, CSS3 (адаптив, сетка, анимации), нативный JavaScript
- Шрифты и иконки — подключены в HTML

## Запуск локально
Открыть `index.html` в браузере или поднять простой сервер:

```bash
python -m http.server 8000
```
и открыть http://localhost:8000
